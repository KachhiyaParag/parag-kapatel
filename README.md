# Parag Kapatel — Portfolio

A responsive, animated, 3D-style developer portfolio built with:

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts

## Free GitHub Pages deployment

### Option 1 — Upload through GitHub website
1. Create a GitHub repository named `parag-portfolio` (or any name).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will publish the site at:
   `https://YOUR-USERNAME.github.io/parag-portfolio/`

### Option 2 — Git command line

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/parag-portfolio.git
git push -u origin main
```

Then enable GitHub Pages in repository Settings → Pages.

## Notes
- No backend is required.
- No build tool is required.
- The Bootstrap and Google Fonts CDN links work on GitHub Pages.
- The 3D cube and card tilt are implemented with CSS/JavaScript.
- Project details are based on the supplied resume.
- Update the LinkedIn URL or contact details if you want to use a different public profile/contact address.
